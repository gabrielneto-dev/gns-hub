# Documentação do gns-hub

Esta pasta reúne as especificações do produto: arquitetura, design, definições funcionais e documentos de referência para implementação.

## Documentos atuais

- [System Design.md](System%20Design.md) — visão do hub, blocos conceituais, navegação, expansão e decisões arquiteturais pendentes.
- [Design.md](Design.md) — identidade visual, cores, tipografia, layout, componentes, estados e acessibilidade.
- [Technology.md](Technology.md) — stack de trabalho para Linux local, alternativas, componentes e plano de medição.
- [Backend.md](Backend.md) — worker de fundo, comandos locais, integrações, dados e segurança.
- [Implementation Plan.md](Implementation%20Plan.md) — etapas e critérios para construir e medir a primeira versão.
- [Audio Output.md](Audio%20Output.md) — primeira funcionalidade: lista de saídas, favoritos e troca imediata do áudio em reprodução.

Novas definições duráveis do produto devem ficar aqui, com links neste índice. A pasta [`Context/`](../Context/README.md) continua sendo a memória operacional dos agentes: estado, decisões, perguntas, fontes e checkpoints. Arquivos de implementação ficarão em suas pastas próprias quando forem criados.
