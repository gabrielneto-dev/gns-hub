# Glossário

- **Hub:** projeto pessoal para reunir atalhos e outras funcionalidades simples no computador.
- **Branch:** área relativamente independente de conhecimento do projeto; a primeira é `desktop-hub`.
- **Registro atômico:** documento pequeno e classificado com ID estável.
- **Checkpoint:** fotografia resumida de continuidade de uma sessão ou marco.
- **L0/L1/L2/L3:** orientação, índice de branch, registro e evidência, respectivamente.
